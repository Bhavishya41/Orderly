
# Orderly

**Orderly** is a full-stack web application designed for seamless **order management**. Built completely from scratch, it handles everything from user authentication to order placement, with modern UI and secure backend APIs.

## 🚀 Features

- **User Authentication**  
  - JWT-based authentication  
  - Password hashing with bcrypt  
  - Google OAuth integration  
  - Email verification via OTP

- **Admin Dashboard**  
  - Manage users and orders (CRUD operations)  
  - Role-based access (admin & user)

- **Ordering System**  
  - OTP verification during order placement  
  - Secure & smooth API communication

- **Responsive Frontend**  
  - Clean, modern UI with Tailwind CSS  
  - Built with React & Next.js

- **Deployment-Ready**  
  - Backend on Render  
  - Frontend on Vercel  
  - Optimized for production

## 🛠 Tech Stack

| Layer         | Tech                                  |
|---------------|--------------------------------------|
| Frontend      | React + Next.js + Tailwind CSS        |
| Backend       | Node.js + Express.js                  |
| Database      | MongoDB                               |
| Authentication| JWT + bcrypt + Google OAuth + OTP     |
| Email Service | Nodemailer (for verification & OTP)   |
| Deployment    | Vercel (Frontend), Render (Backend)   |
| Tools         | Postman, GitHub                       |
